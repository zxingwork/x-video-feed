X 视频浏览

官方 OAuth 登录 · 拉取你账户中的视频帖子

需要先配置 X 开发者应用
  1. 打开 developer.x.com 注册并创建 App
  2. 在 App 设置里添加 Callback URL：http://localhost:3000/api/auth/callback
  3. 启用 OAuth 2.0，类型选 Web App / Confidential Client
  4. 复制 Client ID 与 Client Secret 到项目 .env 文件
  5. 在项目目录运行 npm install 后执行 npm start
关于「推荐视频」
X 官方 API 不提供 App 里「为你推荐」的算法流。 本页可查看：首页时间线（你关注的人发的视频，时间倒序）和我的赞（你点赞过的视频）。

没有找到含视频的帖子

登录你的 X 账户后，即可浏览时间线或点赞中的视频。
